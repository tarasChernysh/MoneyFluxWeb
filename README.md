MoneyFluxWeb is the GitHub Pages legal site for the MoneyFlux iOS app.
`index.html` is the single source of truth — it contains the Privacy Policy and Terms of Use, plus all styling and the app icon reference, in one self-contained page.
Live URL: https://taraschernysh.github.io/MoneyFluxWeb/

**Not the marketing site.** This repo is kept online only so older app builds that still link to
`taraschernysh.github.io/MoneyFluxWeb` keep working (see `moneyfluxwebsite/docs/DEPLOY.md`). The actual
MoneyFlux marketing site, blog and current Privacy/Terms pages live in the separate repo
**`tarasChernysh/MoneyFluxWebsite`** (local checkout: `/Users/taraschernysh/SU/MoneyFluxWebsite`), which is
what the scheduled blog-post task and `content-plan/AUTOPILOT.md` act on. Don't confuse the two repos by name.
